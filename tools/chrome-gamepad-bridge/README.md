# Universal Gamepad — Gamepad Tester Chrome Extension

Enables instant detection of your Universal Gamepad smartphone controller on **Gamepad Tester** (`gamepad-tester.com` / `hardwaretester.com/gamepad`) and HTML5 browser games.

### 🚀 1-Minute Setup in Google Chrome / Brave / Edge:
1. Open your browser and navigate to:
   `chrome://extensions/`
2. Toggle ON **"Developer mode"** in the top-right corner.
3. Click the **"Load unpacked"** button in the top-left.
4. Select the directory:
   `/Users/yashmalik0814gmail.com/Downloads/Universal Gamepad /tools/chrome-gamepad-bridge`
5. Open [gamepad-tester.com](https://gamepad-tester.com)!
6. Your smartphone controller will immediately be detected as:
   `Xbox 360 Controller (STANDARD GAMEPAD Vendor: 045e Product: 028e)`
   with live sticks, triggers, and buttons!
