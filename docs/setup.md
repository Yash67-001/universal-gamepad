# Universal Gamepad — Setup & Quickstart Guide

## Prerequisites
- Node.js 18+ (tested up to Node.js 26)
- Wi-Fi or local network connecting computer and smartphone (or computer Mobile Hotspot)

## Installation & Running

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Build the packages and mobile PWA:**
   ```bash
   npm run build
   ```

3. **Start the Desktop Companion Host:**
   ```bash
   npm start
   ```

4. **Connect your Smartphone:**
   - Open your phone's camera app.
   - Point the camera at the QR code displayed in the desktop console or dashboard.
   - Tap the notification banner to open the controller PWA instantly.
   - Rotate your phone to landscape mode.
   - Start gaming!
